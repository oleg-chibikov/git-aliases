# Правила работы

После каждого завершённого изменения:

1. Запусти подходящие проверки.
2. Создай коммит с изменениями задачи. Посторонние изменения оставь без коммита.
3. Отправь коммит в текущую удалённую ветку без дополнительного запроса.

Если пользователь попросил не коммитить или не отправлять изменения, выполни его указание.
При ошибке проверки, коммита или отправки сообщи причину. Не применяй force push без явного разрешения.
